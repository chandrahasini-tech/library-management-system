# Library Management System (NoSQL)

## Project Description

This project is a Library Management System built using MongoDB (NoSQL).
It allows users to browse, reserve, and manage books with role-based access.

## Roles

* Admin
* Member

## Modules

1. Authentication (Login / Register)
2. User Management
3. Book Management
4. Transactions (Issue / Return)
5. Reservation & Wishlist
6. My Bag (User Dashboard)

## Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Database: MongoDB
